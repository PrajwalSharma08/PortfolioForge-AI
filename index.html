FAQ

Frequently Asked Questions

Do I need to know coding to use this?
Not at all! PortfolioForge AI handles all the code generation. You just answer questions, pick a theme, and customize visually.
Can I use my own GitHub projects?
Yes! Connect your GitHub account and select exactly which repositories you want to showcase in your portfolio.
Is the generated code clean and deployable?
Absolutely. Download a complete Next.js project with clean, production-ready code that you can deploy to Vercel, Netlify, or any host.
Can I customize the design after generation?
Yes! The live editor lets you modify colors, typography, spacing, animations, and section order with instant preview.
What if I don't have a GitHub account?
No problem. You can skip GitHub import and manually add all your projects, skills, and experience through the questionnaire.
Is my data private?
Yes. All data is stored locally in your browser until you choose to download. We never see your information.
